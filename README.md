# Android Control

Distribution repository for a self-hosted Android remote-access app. Development is maintained separately.

Android Control supports hub enrollment, account-scoped passkey browser access, encrypted status, opt-in notifications and user-selected file transfers. New releases add a desktop-style browser workspace and optional phone location/history. Family members have separate accounts; hub administrators have master access to supported device features. This public repository distributes generic signed APKs and user documentation.

Download the APK from [Releases](https://github.com/fblah/android_control/releases). Release assets include the signed APK, checksum and signed update metadata. The APK ships without server configuration; connect to your own hub using an expiring QR invitation and administrator approval.
